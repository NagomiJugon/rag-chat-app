# 開発ポリシー

本リポジトリで開発・データ取得を行う人とAIエージェントが守るルールです。

## 外部サイトからのデータ取得ルール

- RAG用データを外部サイトから取得する前に、アクセスするサイトのルートにある `robots.txt` を必ず確認し、対象サイトに適用されるルールを遵守する。
- `robots.txt` で取得が禁止されているパスにはアクセスしない。
- `robots.txt` を取得・解釈できない場合は取得を開始せず、確認できるまで保留する。
- 別のUser-Agentへの変更、別経路の利用などで拒否ルールを回避しない。
- リダイレクト先が別のホストの場合は、そのホストの `robots.txt` も確認してからアクセスする。
- 対象サイトの利用規約、ライセンス、著作権表示も確認し、より厳しい条件に従う。
- 必要なページだけを取得する。同一ホストへの同時アクセスは1件、リクエスト間隔は最低1秒とする。
- `Retry-After` がある場合は必ず従う。401/403では再試行せず、429/503ではアクセスを止めて負荷を避ける。
- 認証やアクセス制限の回避、個人情報・機微情報の収集、許諾範囲を超える保存・再配布は禁止する。

`backend/rag.py` の取得処理（`SafeFetcher`）はこれらのルールを実装しています。ルールを緩める変更はしないでください。

## 取得したデータの使用範囲

取得したデータは本課題の範囲内でのみ利用し、外部に公開・再配布しない。

## セキュリティ

依存パッケージに既知の脆弱性がないか、更新前とリリース前に確認する。

```bash
npm audit --prefix frontend
pip-audit -r backend/requirements.txt
```

`pip-audit` は事前にインストールしておく。Docker Scout などを使い、Docker イメージもリリース前に確認する。監査結果は実行時点の既知情報に基づくもので、安全性を保証するものではない。
